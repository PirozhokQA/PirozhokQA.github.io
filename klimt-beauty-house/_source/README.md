# Klimt Beauty House — source
Live website: https://pirozhokqa.github.io/klimt-beauty-house/

All text, team information, photo provenance and contact details are in content.mjs.
The pages are generated as static HTML in the parent directory.
Styling and browser interactions are in ../assets/site.css and ../assets/site.js.

## Rebuild
Requires Node.js 20+; no packages are needed.

    node build.mjs

The default base path is /klimt-beauty-house and the default origin is https://pirozhokqa.github.io.
SITE_BASE_PATH and SITE_ORIGIN may be provided for a different deployment.
